<h1 aligne="center">Conversor de Moeda - Challenge Java - Back end - G8 ONE</h1>
  
### Objetivo

O principal objetivo desse projeto foi desenvolver uma aplicação para converter o valor de deterinada moeda de um país para o valor da moeda de outro país, baeando-se na cotação do dia atual. Exemplo converter o Real brasileiro em Dolar Americano e vice-versa.<br>
Para isso foi usado os dados extraído da api [exchangerate-api](https://www.exchangerate-api.com).
O "Conversor de Moedas" ofereçe uma interação textual (via console) com os usuários, proporcionando no mínimo 6 opções distintas de conversões de moedas em um menu. Com uma taxa de conversão dinamicamente obtida por meio da [API](https://www.exchangerate-api.com), garantindo dados precisos e em tempo real para uma experiência mais atualizada e eficaz.

### Desafio

- Implementar uma aplicação utilizando dados de uma API, para converter o valor de determinada moeda em outro valor da moeda de destino escolhida. Para esse desafio, foi utilizado `JAVA`, e `Gson`.
